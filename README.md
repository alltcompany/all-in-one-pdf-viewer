# All in ONE 다중 교재 PDF 뷰어

하나의 `index.html` 안에 다음 세 교재가 포함되어 있습니다.

- All in ONE N제 수학Ⅰ - 46페이지
- All in ONE N제 수학Ⅱ - 52페이지
- All in ONE N제 확률과 통계 - 44페이지

## 주요 기능

- 첫 화면에서 교재 표지를 선택해 바로 열람
- 상단 책 아이콘 또는 모바일 `더보기 > 교재 선택`으로 교재 변경
- 두쪽 책 넘김 모드
- 두쪽 스크롤 모드
- 책장 넘김 3D 모션
- 페이지 썸네일, 페이지 이동, 확대/축소, 회전
- 문서 검색, 판서, 다운로드, 인쇄, 전체화면
- 교재·페이지·보기 모드가 포함된 공유 주소 생성
- 모바일 최적화

## 배포 파일

- `index.html`: 실제 뷰어. PDF 3개가 내부에 포함된 단일 HTML 파일
- `.nojekyll`: GitHub Pages가 파일을 그대로 배포하도록 하는 빈 파일
- `GITHUB_UPDATE_GUIDE.md`: 기존 GitHub Pages 사이트 교체 배포 안내

PDF 파일은 별도로 GitHub에 올리지 않아도 됩니다.
