# All in ONE PDF Viewer

## 보기 모드

1. **두쪽 책 넘김**
   - 첫 페이지와 마지막 페이지는 한 장으로 표시
   - 중간 페이지는 `2–3`, `4–5`처럼 맞쪽으로 표시
   - 다음/이전 이동 시 실제 책장을 넘기는 것처럼 한쪽 종이가 중심 책등을 기준으로 약 0.9초 동안 부드럽게 회전
   - 넘어가는 앞면과 뒷면에 각각 실제 PDF 페이지를 표시
   - 종이 음영, 움직이는 그림자, 책등 음영 적용
   - 앞표지와 뒤표지는 3D 표지 열림/닫힘 모션 적용

2. **두쪽 스크롤**
   - 맞쪽 단위가 세로로 연속 배치
   - 스크롤로 아래로 내려가며 열람
